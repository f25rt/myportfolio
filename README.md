# Farnsbert N. Saberon — Portfolio

Static software engineer portfolio built with HTML, CSS, and JavaScript. No package install or framework build is required.

## Deploy on Render
This repository includes a Render Blueprint in `render.yaml`.

1. Push this repository to GitHub.
2. In Render, choose **New → Blueprint** and connect this repository.
3. Render reads `render.yaml`, publishes the page, and assigns an `onrender.com` URL.

For manual setup, create a Render Static Site with build command `mkdir -p public && cp index.html public/index.html` and publish directory `public`.

## Local preview
Open `index.html` directly in a browser.
